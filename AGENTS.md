# AGENTS.md

Правила для работы в этом репозитории. Их читает любой агент, не только Cursor. Дополняют `.cursor/rules/`.

## Размер загружаемых файлов

У каждой загрузки файла свой предел в байтах. Общий потолок Kestrel, в том числе лимит дампа базы, предел конкретного действия не заменяет.

- Предел задаётся на действии и проверяется до чтения файла в память.
- Файл больше предела не сохраняется. Ответ — ошибка этого действия, не разбор содержимого.
- `RequestSizeLimit` считает весь запрос, вместе с полями multipart. Если из-за этого файл на самом пределе не доходит до действия, у запроса оставляют небольшой запас, а точный размер файла проверяют отдельно.
- Число предела своё у каждого файла: дамп базы — 100 МБ, шаблон настроек группы и архив подписи — 2 МБ.
