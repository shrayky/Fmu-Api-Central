# Входящие ЭТрН через Saby

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Central забирает у Saby транспортные накладные, ждущие приёмки грузополучателем, и по кнопке в WebApp подписывает титул грузополучателя сертификатом организации.

**Architecture:** Подключения оператора лежат списком на `OrganizationEntity`. Входящий документ и состояние опроса — отдельные документы CouchDB, журнал команд — своя база. Domain знает только правило приёмки и сдвиг пары идентификаторов; JSON-RPC, сессию, XML и подпись держит `EtrnSaby`. Application опрашивает подключения и пишет журнал, WebApi отдаёт `api/etrn`, WebApp показывает три вкладки.

**Tech Stack:** .NET 10, xUnit, CouchDB.NET 4.1.0, CryptoPro.Security.Cryptography, Webix.

## Global Constraints

- Живой Saby и КриптоПро в тестах не вызываются; HTTP подменяется обработчиком, порт подписи — подделкой.
- Сертификат и пароль контейнера — только в `TrueApiIntegrationSettings`; своей копии у подключения нет. Шлюз читает их и при выключенном Честном знаке.
- Один сертификат — одна сессия процесса WebApi; `СБИС.Выход` не вызывается; вход в журнал не пишется.
- Оператор на документе и строке журнала — объект `Operator` (`ConnectionId`, `Type`, `Name`); пустое имя заменяется подписью типа.
- Id накладной: `doc:{organizationId}:{connectionId}:{operatorDocumentId}`; состояние опроса: `sync:{connectionId}`.
- Размер страницы 50, первая пауза воркера 30 секунд, интервал из настроек читается на каждом круге.
- Ошибка Saby в документе и состоянии опроса обрезается до 300 символов.
- `Sending` возрастом ровно 10 минут не трогается; старше — сверка с этапом.
- Журнал: успех живёт сутки, ошибка — семь; ровно срок остаётся, на секунду старше удаляется.
- `api/etrn` доступен только пользователю Central; канал `api/Agent` его не принимает.
